เว็บ ຊ້າງໃຫຍ່ ໂຢເກີດ — วิธีขึ้นเว็บ

1. เว็บนี้เป็นไฟล์ static ทั้งหมด (HTML/CSS/JS/รูป) ไม่มีฐานข้อมูล ไม่ต้องตั้งค่าเซิร์ฟเวอร์
2. อัปโหลด "ทุกไฟล์ในโฟลเดอร์นี้" ไปไว้ที่ root ของโดเมน (ไฟล์ index.html ต้องอยู่ชั้นบนสุด)
   ใช้ได้กับ Cloudflare Pages, Vercel, Netlify, cPanel/hosting ทั่วไป, nginx, Apache
3. ต้องเปิดผ่าน https:// (เปิดไฟล์ด้วยการดับเบิลคลิกจากเครื่องจะไม่ทำงาน)
4. ไม่ต้องตั้งค่า rewrite/redirect — หน้าที่ 2 ใช้ลิงก์แบบ #find
5. สำคัญ: โดเมน *.pages.dev และ *.vercel.app เปิดไม่ได้ในลาว ต้องผูกโดเมนของตัวเอง
6. (ไม่บังคับ) ตั้ง cache นานๆ ให้โฟลเดอร์ /assets/ ได้ เพราะชื่อไฟล์เปลี่ยนทุกครั้งที่ build
   ส่วน /img/ และ /frames/ ถ้าตั้ง cache นาน ต้องเปลี่ยนชื่อไฟล์เมื่อเปลี่ยนรูป
7. เว็บดึงฟอนต์จาก Google Fonts และแผนที่จาก Google Maps (ต้องต่ออินเทอร์เน็ต)
